# コダマ会議

サーバーを通さない P2P のウェブ会議アプリ。ビルド不要、`index.html` を開くだけで動く1ファイル構成。

## 遊べるURL

https://tanakatakeshi811-spec.github.io/kodama-kaigi/

## 特徴

- サーバーレスの P2P 通話(PeerJS / WebRTC)。合言葉(4文字)でルームを作成・参加
- 公開ルーム検索(ロビー方式、専用サーバー不要)
- 字幕・翻訳・チャット(音声入力対応)・反応・挙手
- 招待URL・QRコード表示
- YouTube同時視聴(全員で再生同期)
- 画面共有+自分のカメラを同時表示
- 映像エフェクト(モザイク・黒塗り)・音声ボイスチェンジャー
- 同時通訳ウィジェット(自分だけが見える、聞き取り→自動翻訳)

## 動かし方

`index.html` をブラウザ(Chrome / Edge 推奨)で直接開くだけ。マイク・カメラの許可が必要な機能もある。
